## 0. 한 장 요약

```
┌─ 상단: [☰] LIGHT ─────────────────────────┐   ☰ = 사이드바 (교회 안내 · 전체 메뉴)
│                                            │
│              (탭 화면)                      │
│                                            │
└─ 하단 탭: 홈 · 말씀 · 소식 · 자료 · 더보기 ─┘   자주 쓰는 것 / 나·앱
```

| 진입점 | 역할 | 화면 수 | 로그인 |
|---|---|---|---|
| 하단 **말씀** | 라이브 · 지난 설교 | 1 | 불필요 |
| 하단 **소식** | 공지 목록 · 상세 | 2 | 회원 공지만 필요 |
| 하단 **자료** | 주보 · 사진첩 · 월례회 · 회의록(· 예산안) | 허브 1 + 8 | **필요 (회원)** |
| 하단 **더보기** | 내 계정 · 설정 · 앱 정보 | 1 + 3 | 일부 |
| **사이드바 ☰** | 교회 안내(소개·처음 오시는 분·오시는 길·예배와 모임 등) | 1 + 6 | 불필요 |
| 공통 | 로그인 · 로그인 게이트 | 2 | — |

**역할 구분 원칙 (중복 방지)**
- **하단 탭 = 매주 쓰는 것.** 말씀 보기, 공지 확인, 주보·사진첩 보기
- **사이드바 = 교회 안내.** 처음 온 사람이 찾는 정보(소개·오시는 길·예배 시간) + 전체 메뉴 바로가기
- **더보기 탭 = 나와 앱.** 로그인·내 정보·로그아웃·문의·앱 정보
- 같은 화면을 두 곳에서 열 수는 있지만(예: 사이드바의 "주보" → 자료 탭의 주보), **화면 자체는 하나만 만든다**

## 2. 하단 탭 화면

### 2-1. 말씀 탭 `/sermons` — P1

| 영역 | 내용 |
|---|---|
| 상단 | **라이브 카드** — 진행 중이면 빨간 "LIVE" + 썸네일 + [지금 보기]. 없으면 다음 예배 시간("주일 14:00") |
| 목록 | 지난 말씀 — 썸네일 · 제목 · 날짜. 무한 스크롤 |
| 누르면 | YouTube 앱으로 (홈의 "최근 말씀"과 같은 동작, 이미 `openExternal` 있음) |
| API | `GET /api/sermons/live` · `GET /api/sermons?page=` (권한 G) — **`SermonsApi` 이미 있음** |
| 웹 대응 | `/sermons` · `/sermons/all` (WIREFRAME §5) |
| 빈/오류 | 라이브 실패는 조용히 숨기고 목록만 (BE가 키 없으면 `data:null`) |

### 2-2. 소식 탭 `/news` — P1

**① 공지 목록**

| 영역 | 내용 |
|---|---|
| 목록 | 📌 고정 글 먼저 → 최신순. 제목 · 날짜 · 📎(첨부 있으면) |
| 범위 | 비로그인: 공개 공지만. 로그인: 공개 + 회원 공지 **합쳐서** (웹과 같음, 회원 전용 뱃지 없음 — DECISIONS 09-16) |
| 하단 | 비로그인이면 "로그인하면 회원 공지도 볼 수 있어요" 한 줄 |
| API | `GET /api/posts?category=NOTICE_PUBLIC` + `NOTICE_MEMBER`(로그인 시) — `PostsApi` 있음 |
| ⚠️ | 두 분류를 합칠 때 **고정 우선 정렬을 다시 해야 한다** — 웹에서 이걸 빠뜨려 고정이 안 먹었다(10-07 수정) |

**② 공지 상세** `/news/:idOrSlug`

| 영역 | 내용 |
|---|---|
| 상단 | 📌 · 제목 · 작성자 · 날짜 |
| 본문 | **리치텍스트 JSON 렌더러** (웹 `PostBodyView`와 같은 노드: 문단·제목·목록·굵게·링크·이미지) — **회의록·예산안 상세도 이걸 재사용** |
| 첨부 | 📎 파일명 · 크기 → 누르면 내려받기 후 열기 |
| API | `GET /api/posts/{idOrSlug}` · `GET /api/files/{id}` (302 → 서명 URL) |
| ⚠️ | 회원 공지 첨부는 **로그인 쿠키가 필요**하다. 외부 브라우저로 열면 쿠키가 없어 401 → **앱 안에서 dio로 받아** 저장·열기 해야 한다 |

### 2-3. 자료 탭 `/resources` — P2 (회원 전용)

**① 자료 허브**

```
비로그인                         로그인(회원)                 로그인(임원↑)
┌──────────────────────┐        ┌────────┬────────┐          + [예산안] 카드
│ 🔒 회원 전용 자료예요   │        │ 📄 주보 │ 📷 사진첩│          + "관리는 웹에서 →" 링크
│ 주보·사진첩·월례회·회의록│        ├────────┼────────┤
│      [로그인]          │        │ 📑 월례회│ 📝 회의록│
└──────────────────────┘        └────────┴────────┘
```
- 월례회 카드에는 **열람 기간이면 "열람 중 · ~10/9 23:59"** 배지 (가장 놓치기 쉬운 자료)

**② 주보** — 최신 주보 뷰어 + 지난 주보

| 영역 | 내용 |
|---|---|
| 뷰어 | 장 단위 좌우 스와이프 · 핀치 줌 · "1/4" 표시. 이미지는 장변 2048px |
| 지난 주보 | 날짜 목록 → 누르면 그 주보 뷰어 |
| API | `GET /api/bulletins/latest` · `GET /api/bulletins?page=` · `GET /api/bulletins/{id}` (M) |
| 웹 대응 | WIREFRAME §6·§12, FR-BUL |
| 내려받기 | 1차 제외 (웹은 장별 내려받기 있음 — §7 결정 D5) |

**③ 사진첩** — 앨범 목록 → 앨범 → 크게 보기

| 화면 | 내용 |
|---|---|
| 앨범 목록 | 대표 사진 · 제목 · 날짜 · 장 수 |
| 앨범 상세 | 3열 그리드, 끝까지 내리면 더 (커서 페이징 `cursor=`) |
| 크게 보기 | 좌우 스와이프 · 줌. ⋮ → **신고·삭제 요청**(사유 입력) |
| API | `GET /api/albums` · `GET /api/albums/{id}/photos?cursor=` · `POST /api/photos/{id}/report` (M) |
| 다운로드 | **없음** — 웹도 09-10에 제거(DECISIONS) |
| ⚠️ | 신고 완료 문구를 "임원이 확인 후 처리"라고 약속하지 말 것 — 지금 BE는 로그만 남긴다(점검 🟠-13). "요청이 접수됐어요" 정도로 |

**④ 월례회 자료** — 목록 → 뷰어

| 화면 | 내용 |
|---|---|
| 목록 | 웹과 같은 **버튼 색 규칙**: 초록 [열람하기](기간 안) · 회색 비활성 [열람 전]/[열람 종료](회원, 기간 밖) · 갈색 [임원 열람](임원↑, 기간 밖) — DECISIONS 10-07 |
| 뷰어 | 페이지 이미지 세로 스크롤 · 남은 시간 표시 · "페이지마다 이름이 표시됩니다" 안내 |
| API | `GET /api/meetings` · `GET /api/meetings/{id}` · `GET /api/meetings/{id}/pages/{n}` (M, 기간 밖 회원 403) |
| ⚠️ | 페이지 이미지는 **쿠키가 붙은 요청**이어야 한다 → `Image.network` 기본값으로는 401. dio로 받아 `Image.memory` 등 |
| ⚠️ | 30분 넘게 보면 토큰이 만료돼 다음 페이지가 실패한다(웹 점검 🟡-2) → 실패 시 refresh 1회 후 재시도 |
| 제안 | **화면 캡처 막기(FLAG_SECURE)** — 웹은 못 막지만 앱은 막을 수 있다 (§7 결정 D3) |

**⑤ 회의록 · 예산안** — 목록 → 상세

| 항목 | 내용 |
|---|---|
| 회의록 | 회원(M) — 목록 · 상세(소식 상세 화면 재사용) |
| 예산안 | **임원 이상만** 카드가 보임. 회원이 주소로 접근하면 서버가 404 |
| API | `GET /api/posts?category=MINUTES|BUDGET` · `GET /api/posts/{id}` |

### 2-4. 더보기 탭 `/more` — P2

```
┌ 내 계정 ─────────────────────┐     비로그인이면:
│ 홍길동 · 임원                 │     [로그인]  가입은 웹에서 →
│ 내 정보  ›                    │
│ 비밀번호 변경  ›               │
│ 로그아웃                      │
├ 교회 ────────────────────────┤
│ 문의하기 (전화·문자)  ›        │
│ 관리 화면 (웹)  ›   ← 임원↑만  │
├ 앱 ──────────────────────────┤
│ 개인정보 처리방침  ›           │
│ 오픈소스 라이선스  ›  (#211 등록됨)│
│ 버전 1.0.0                    │
└──────────────────────────────┘
```

| 화면 | 내용 | API |
|---|---|---|
| 내 정보 | 이름·아이디(읽기 전용) · **연락처 수정** | `GET/PATCH /api/auth/me` |
| 비밀번호 변경 | 현재·새·확인 3칸. **틀리면 "현재 비밀번호가 올바르지 않습니다" + 세 칸 모두 비움** (웹과 같게, DECISIONS 10-07 (3)) · 서버는 `field:"password"`로 줌 | `POST /api/auth/password/change` |
| 로그아웃 | 확인 후 로그아웃 → **캐시된 회원 데이터 비우기**(웹 점검 🟠-4 교훈) | `POST /api/auth/logout` |
| 탈퇴 | 1차는 **웹으로 연결** (되돌릴 수 없는 동작, 결정 D2) | — |

### 2-5. 로그인 · 로그인 게이트 (공통) — **P1, 다른 회원 화면의 선행 작업**

| 화면 | 내용 |
|---|---|
| 로그인 | 아이디 · 비밀번호 · [로그인]. 실패·잠금은 **같은 문구 하나** (SPEC_API §2.3) |
| 아래 링크 | 회원가입 · 비밀번호 찾기 → **웹으로** (결정 D2). 카카오 로그인은 보류(버튼 없음) |
| 로그인 게이트 | 회원 화면에서 401이면 그 자리에 "로그인하면 볼 수 있어요 [로그인]" — 로그인 후 **원래 화면으로 복귀** |
| 세션 만료 | `ApiClient`의 세션 만료 알림(이미 있음) → 게이트 표시 |
| 로그인 상태 | 앱 전체가 아는 상태(AuthState) 하나 — 자료 탭·더보기·사이드바가 함께 씀 |
| API | `POST /api/auth/login` · `GET /api/auth/me` · `POST /api/auth/logout` |

## 3. 사이드바 (☰ 드로어)

**여는 법:** 모든 탭 상단 왼쪽 ☰ (또는 화면 왼쪽 끝에서 밀기). 홈의 [처음 오시는 분]·[오시는 길] 버튼도 여기 화면으로 연결.

```
┌──────────────────────────┐
│  (엠블럼)  LIGHT           │
│  홍길동님 · 임원  / [로그인] │
├──────────────────────────┤
│ 처음 오시는 분      ★      │
│ 오시는 길                  │
│ 예배와 모임                │
│ 청년교회 소개              │
│ 조직도                     │
├──────────────────────────┤
│ 말씀 · 소식 · 자료 바로가기  │  → 하단 탭 전환
├──────────────────────────┤
│ 새가족 등록                │
│ 문의하기                   │
│ 인스타그램 · 유튜브 ↗       │
└──────────────────────────┘
```

| 화면 | 내용 | 데이터 | 웹 대응 | 우선 |
|---|---|---|---|---|
| **처음 오시는 분** ★ | 예배 흐름(도착→안내→예배→마을모임), 드림센터는 본당과 **다른 건물**이라는 안내, [새가족 등록] | 정적 | `/welcome` (WIREFRAME §2 "최우선 페이지") | **P1** |
| **오시는 길** | 주소(복사) · [네이버 지도]·[카카오맵] 앱으로 열기 · 주차(P1·P2 농협주차장) · 대중교통 | 정적 (`frontend/src/content/location.ts`·`parking.ts`) | `/location` §8 | **P1** |
| **예배와 모임** | 청년예배 시간·장소 · 마을모임 · 그 밖의 모임 표 | 정적 (`content/worship.ts`) | `/worship` §4 | P1 |
| 청년교회 소개 | 비전(Live In God, Help The other) · 공동체 사진 | 정적 | `/about` §3 | P2 |
| 조직도 | 섬기는 사람들 | 정적 | `/about/organization` | P3 |
| 새가족 등록 | 이름·연락처·성별·연령대·경로·하고 싶은 말 · **개인정보 동의** 필수 · 완료 화면 + 오시는 길 | `POST /api/newcomers` (G) | `/welcome/register` §9 | P3 |
| 문의하기 | 전화·문자 버튼, 담당자 | 정적 (`content/contact.ts`) | `/contact` | P2 |

> ⚠️ **정적 내용은 웹 `frontend/src/content/*.ts`와 같은 값이어야 한다.** 예배 시간이 바뀌면 두 곳을 고쳐야 한다.
> 1차는 복사해서 쓰고, 파일 상단에 "원본: frontend/src/content/worship.ts"를 적어 둔다. (나중에 API로 옮길지는 별도 논의)
> ⚠️ `/welcome/route`(오는 길 사진 슬라이드)는 **임시 사진**이라 앱에 넣지 않는다 (DECISIONS 09-15).

## 4. 화면 흐름

```
앱 시작 → (스플래시 · 인트로 #218) → 홈
  ├─ ☰ 사이드바 ─ 처음 오시는 분 ─ [새가족 등록]
  │              ├ 오시는 길 ─ 지도 앱 ↗
  │              ├ 예배와 모임 / 소개 / 조직도 / 문의
  ├─ 말씀 ─ 라이브·지난 말씀 ─ YouTube ↗
```
