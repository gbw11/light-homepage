## 2. 이 측정으로 찾아 고친 결함 4건

전부 **레이아웃이 밀리는 문제(CLS)와 대비**였고, 원인은 두 종류뿐이었다.

### 2.1 로딩 표시가 "불러오는 중..." 한 줄이었다 (3건)

공개 열람 전환 이후 이 화면들은 데이터를 **클라이언트에서** 가져온다(서버에서
부르면 백엔드 없는 환경에서 정적 생성이 멈춘다 — `/news`가 실제로 CI를 깨뜨린
전례가 있다). 그런데 로딩 자리가 한 줄짜리 텍스트라, 목록이 도착하는 순간
아래 내용이 **푸터까지 통째로** 밀려났다.

| 화면 | CLS | 성능 |
|---|---|---|
| `/sermons` | 0.537 → **0.000** | 76 → **98** |
| `/bulletin` | 0.278 → **0.000** | 81 → **95** |
| `/photos` | 0.246 → **0.000** | 82 → **95** |
| `/news` | 0.112 → **0.014** | 91 → **93** |

`/sermons`가 가장 심했던 것은 **PR #70에서 하드코딩 더미를 API 조회로 바꾸면서**
생긴 문제다. 카드 12개가 한꺼번에 나타나니 밀리는 거리도 그만큼 컸다.

고친 방식은 하나다: **로드 후와 같은 격자·같은 비율·같은 줄높이로 미리 그린다.**
`/news`만 0.014가 남는데, 공지 수는 서버가 정하는 값이라 화면이 미리 알 수 없다
(6줄로 잡았다). 남은 값은 "좋음" 기준(0.1) 안에 있다.

### 2.2 경고 문구의 대비가 4.5:1에 못 미쳤다 (1건)

`/welcome`·`/location`의 **"⚠️ 청년예배는 본당이 아니라 드림센터 4층입니다"** —
`PLAN §4.2`가 사이트에서 가장 중요하다고 지정한 바로 그 문장이다.

| | 값 |
|---|---|
| 관측 | `#c62a2e` on `#f1ddd2` = **4.24:1** ❌ |
| 요구 (WCAG AA) | 4.5:1 |

`--color-red-500`은 접근성 개편(PR #62) 때 **페이지 배경 `#f6f1e4` 위 4.94:1**로
검증된 값이다. 그런데 이 블록만 `bg-red-500/10` 틴트로 **다른 표면**을 만들었고,
그 표면 위에서 다시 재지 않았다. 토큰이 틀린 게 아니라 **검증된 조건을 벗어나
쓴 것**이다.

고친 방식: 경고 신호는 **테두리**가 지고 글자는 기본 색으로 둔다(11.81:1).
`PostForm`·`MeetingUploadForm`의 경고 블록이 이미 이 형태여서 **화면 간 생김새도 맞았다.**
다크 모드도 5.26 → 12.25로 함께 올라간다.

→ `/welcome`·`/location` 접근성 **96 → 100**

## 3. ⚠️ 측정할 때 빠졌던 함정 — 다음 사람이 반복하지 않도록

**낡은 `next start`가 살아 있는 채로 재빌드하면, 스타일이 없는 페이지를 측정하게 된다.**

- 서버는 기동 시점의 빌드를 기억한다. 그 아래에서 `npm run build`를 다시 돌리면
  HTML은 옛 해시(`2gf94….css`)를 가리키는데 디스크에는 새 파일(`3by1l….css`)만
  남아 **CSS가 500**이 된다
- `pkill -f "next start"`는 **Windows에서 매칭에 실패한다** — 죽었다고 생각하고 계속 진행하게 된다
- 이때 측정치는 **거짓으로 좋아 보인다.** 스타일이 없으면 밀릴 레이아웃도 없어서
  CLS가 0으로 나온다. 실제로 이 함정에 걸린 채 "CLS 0.278 → 0.000, 다 고쳤다"는
  결론을 한 번 냈다가, 스크린샷에 스타일 없는 화면이 찍혀서 발견했다
- 곁가지 증상: `target-size`가 전 페이지에서 실패한다(`min-h-11`인 버튼이
  16×24로 측정된다). **이게 보이면 CSS부터 의심할 것**

그래서 측정 전에 **CSS가 200인지 반드시 확인한다**:

```sh
PID=$(netstat -ano | grep ':3000 ' | grep LISTENING | awk '{print $5}' | head -1)
[ -n "$PID" ] && taskkill //PID "$PID" //T //F      # pkill 말고 이걸 쓴다
npm start &
CSS=$(curl -s http://localhost:3000/about | grep -o '/_next/static/chunks/[^"]*\.css' | head -1)
curl -s -o /dev/null -w '%{http_code}\n' "http://localhost:3000$CSS"   # 200이어야 한다
```
