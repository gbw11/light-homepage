# 인계 브리핑 (`docs/handoff/`)

`docs/backend/BACKEND_HANDOFF.md`는 **시간순 로그**다 — 프론트 작업 중 백엔드가 알아야 할
내용이 생길 때마다 위에 쌓인다. 길어지면 "지금 내가 뭘 해야 하는가"를 뽑아내기
어렵다.

이 디렉터리는 그중 **하나의 기능을 BE가 바로 착수할 수 있는 형태로 떼어낸
실행용 브리핑**을 둔다. 결정할 것 → 설정할 것 → 구현 체크리스트 순서로 적는다.

- 파일명: `YYYY-MM-DD-<기능>.md`
- 로그(`BACKEND_HANDOFF.md`)와 **내용이 겹치는 것은 정상**이다. 로그는 이력,
  여기는 실행용이다
- 반영이 끝나면 지우지 않고 문서 머리에 `✅ 반영됨 (YYYY-MM-DD)`를 남긴다
