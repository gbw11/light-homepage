### 1.2 의도적으로 보류한 성능 항목 4건
근거는 `PERF_SWEEP_2026-08-25.md` "의도적으로 보류한 것"에 있다. 전부
"별도 단위로" 표시.

- **공개 페이지의 `GET /auth/me` 왕복 제거** — 모든 공개 페이지 첫 로드에
  인증 조회가 나간다. 헤더 구조 개편이 필요
- **이미지 리사이즈 Web Worker화** — 업로드 시 WebP 인코딩(장당 2회)이 메인
  스레드에서 돈다. `OffscreenCanvas`가 transferable이라 이전 자체는 어렵지 않다
- **`SiteFooter` 라우트 그룹 재구성** — `usePathname` 하나 때문에 클라이언트
  래퍼가 루트 레이아웃에 있다
- **`Accordion`을 `<details>`로** — `/welcome`의 유일한 클라이언트 경계
