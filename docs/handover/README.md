# 작업 인계 (`docs/handover/`)

**하루를 마칠 때, 끝내지 못한 것을 여기 적는다.** 다음 날 이 디렉터리의 **가장
최근 날짜 파일**을 먼저 읽고 시작한다.

`WORKPLAN.md §10`(결정 로그)이나 `BACKEND_HANDOFF.md`와 역할이 다르다.

| 문서 | 담는 것 | 시점 |
|---|---|---|
| `WORKPLAN.md §10` | 확정된 결정·완료 사실 | 결정이 날 때마다 |
| `BACKEND_HANDOFF.md` · `handoff/` | 백엔드가 알아야 할 것 | 계약이 걸릴 때마다 |
| **`handover/`** | **아직 안 끝난 것 · 검증 못 한 것 · 남이 답해야 하는 것** | 하루 끝 |

적는 순서를 지킨다: **못 한 것이 먼저, 한 것이 나중.** "오늘 뭘 했다"로 시작하는
문서는 다음 날 아무 도움이 되지 않는다.
